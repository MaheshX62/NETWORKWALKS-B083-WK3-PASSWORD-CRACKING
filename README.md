🔐 NETWORKWALKS-B083-WK3-PASSWORD-CRACKING

📌 Week 03 Cybersecurity Internship Project

This repository contains my Week 03 practical work and project evidence
completed as part of the Cybersecurity Program at NetworkWalks.

The work covers two cybersecurity activities:

W3-PM1: Password Cracking with JTR

W3-PM2: Password Cracking with NetworkWalks Tools

Scope: These activities were performed within the assigned NetworkWalks educational lab environment using the supplied protected PDF.

🎯 Objectives

The main objectives of this week's practical work were to:

Understand the basics of password cracking.

Understand how password hashes are extracted from protected files.

Use John the Ripper and Johnny for password-cracking practice.

Use the NetworkWalks Hash Calculator.

Use the NetworkWalks Password Cracker.

Verify the recovered password by opening the protected PDF.

Document the practical work and supporting evidence.

🔐 W3-PM1: Password Cracking with JTR

Objective

Recover the password of the supplied My Locked PDF1.pdf
using John the Ripper (JTR) and Johnny.

Process

Prepared the supplied encrypted PDF.

Extracted the PDF password hash.

Saved the hash in a text file.

Loaded the hash into Johnny.

Started the password-cracking attack.

Recovered the password.

Verified the password by opening the protected PDF.

Result

The JTR password-cracking lab was successfully completed.

📊 Findings & Observations

1. Password Hash Extraction

The practical demonstrated how password-related hash data
can be extracted from a protected PDF for authorized security testing.

2. Password Cracking

Both JTR and the NetworkWalks Password Cracker were used
to test the strength of the supplied PDF password.

3. Password Verification

The recovered password was successfully used to open
the protected PDF.

4. Password Security

The practical demonstrated the importance of using strong
and difficult-to-guess passwords.

These observations were obtained from the authorized
NetworkWalks training lab and should not be treated as
permission to test unrelated files or systems.

⚠️ Security Considerations

Password-cracking techniques can be used for legitimate
security testing, but they must only be performed:

Within an authorized scope

Against files or systems for which permission has been obtained

Using documented testing procedures

Without accessing unauthorized data
