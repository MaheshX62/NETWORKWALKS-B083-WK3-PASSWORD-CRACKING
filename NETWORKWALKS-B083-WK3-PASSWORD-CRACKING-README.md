This repository contains my **Week 03 practical work and project evidence**

The main objectives of this week's practical work were to:

# 🔐 W3-PM1: Password Cracking with JTR

## Objective

Recover the password of the supplied **My Locked PDF1.pdf**
using **John the Ripper (JTR)** and **Johnny**.

## Process

1. Prepared the supplied encrypted PDF.
2. Extracted the PDF password hash.
3. Saved the hash in a text file.
4. Loaded the hash into Johnny.
5. Started the password-cracking attack.
6. Recovered the password.
7. Verified the password by opening the protected PDF.

## Result

The JTR password-cracking lab was **successfully completed**.

# 🔑 W3-PM2: Password Cracking with NetworkWalks Tools

## Objective

Recover the password of the supplied **My Locked PDF1.pdf**
using the **NetworkWalks Hash Calculator** and
**Password Cracker**.

## Process

1. Uploaded the protected PDF to the Hash Calculator.
2. Extracted the PDF password hash.
3. Copied the complete hash value.
4. Submitted the hash to the Password Cracker.
5. Started the password-cracking process.
6. Recovered the password.
7. Verified the password by opening the protected PDF.
